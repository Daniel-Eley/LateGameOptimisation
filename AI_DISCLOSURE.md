# AI development disclosure

LateGameOptimisation is developed with substantial assistance from **OpenAI Codex**, directed by **Daniel Eley**. AI use is disclosed so users can make an informed decision about reviewing, building and running the project.

## Work performed so far

The starting project was generated by BTD6 Mod Helper. Codex then generated the custom frame-time diagnostic implementation and standalone checks, rewrote the project build configuration and CI workflow, and wrote the project documentation, security policy and development plan. Codex also used development tools to build the project, run checks and publish the source repository at the owner's request. The gameplay-preservation requirement comes from the project owner.

The original template and third-party dependencies were not authored by this project's AI session. AI assistance does not grant rights to third-party game code or dependencies; their own licenses still apply.

## Review and validation limits

AI-generated code can contain mistakes. The owner directing development is not evidence of an independent human code audit. No such audit or in-game compatibility test has been completed or claimed. Local compilation and standalone diagnostic checks passed, and the initial GitHub CI run passed. Those checks do not establish gameplay equivalence, security or a performance improvement.
